# Гипотезы и исследовательские идеи (Hypotheses)

### HYP-001: Использование Mesa RADV GFX11 напрямую через IOUserClient без xlat
- **Формулировка:** Если использовать нативный winsys RADV (как в Cobalt64), то транслятор командного потока `xlat` не нужен для запуска Vulkan и Metal приложений (через Metal-on-Vulkan). RADV самостоятельно генерирует валидные командные буферы GFX11 PM4.
- **Критерий проверки:** Успешная сборка синтетического буфера команд через структуру RADV Winsys и проверка его валидности на парсере PM4 RDNA 3.
- **Статус:** Требует проверки после реализации базового kext/модуля.

### HYP-002: Моделирование RDNA 3 через виртуальные интерфейсы (Mock Kernel/Kext)
- **Формулировка:** До физического доступа к целевому ноутбуку можно реализовать userspace mock-сервер или shim для интерфейса `R3N` (аналог `N48N`), позволяющий верифицировать протокол обмена Mesa RADV и тесты вызова аллокаций памяти прямо на `drip-pc`.
- **Критерий проверки:** Прохождение тестов `n48native` против локального mock-сервера под Linux.
- **Статус:** Запланировано в Этапе 1.
