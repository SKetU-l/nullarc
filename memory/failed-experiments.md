# Неудачные эксперименты (Failed Experiments)

В этот документ заносятся неудачные эксперименты, сбои и установленные причины.

### FAIL-001: Попытка сборки тестов IB-уровня xlat12 без закрытых фикстур Apple
- **Дата:** 11.10.2026
- **Окружение:** `workstation`, Clang 22.1.8.
- **Команда проверки:** `make -C reference/Cobalt64/src/xlat12 test`
- **Фактический результат:**
  ```
  make: *** No rule to make target 'tests/fixture_r30_blit_ib.h', needed by 'build/test_xlat12_ib'. Stop.
  ```
- **Установленная причина:** Репозиторий Cobalt64 намеренно не содержит проприетарные дампы буферов команд (IB), полученные из драйверов Apple (`tests/fixture_r30_blit_ib.h`), о чем явно сказано в `BUILDING.md`. Тесты, зависящие от этих фикстур, не могут быть собраны из публичного репозитория без синтетических заменителей.

### FAIL-002: Попытка идентификации целевого ноутбука через Host `laptop` в SSH
- **Дата:** 11.10.2026
- **Окружение:** `workstation`, опрос `192.168.1.200` по SSH.
- **Команда проверки:** `ssh laptop "lspci -nn | grep -iE 'vga|3d|display'"`
- **Фактический результат:** Устройство содержит `Intel Core i3-3217U + NVIDIA GeForce GT 740M`, после чего ушло в оффлайн (`No route to host`).
- **Установленная причина:** Конфигурация в `~/.ssh/config` ссылается на старый тестовый ноутбук, а не на целевой ноутбук с AMD RDNA 3.
