# AGENTS.md — Инструкции для автономных агентов проекта RDNA 3

## 1. Контекст и границы проекта
Проект нацелен на исследование, реализацию и поэтапное тестирование поддержки GPU AMD архитектуры RDNA 3 (GFX11) на основе архитектурных решений проекта Navi48 (`Almosst-DEV/Cobalt64`).

### Роли машин
- **Основной ПК (`drip-pc`):** Управляющая станция и машина сборки (Host / Controller). Arch Linux x86_64, Ryzen 5 5600X, 15 GB RAM, GPU Navi 10 (RDNA 1, RX 5700 XT). Здесь выполняются компиляция, хостовые юнит-тесты, анализ исходников и координация.
- **Тестовый ноутбук:** Целевое устройство с AMD RDNA 3. На нем выполняются исключительно верификационные аппаратные тесты.

## 2. Жесткие правила безопасности (Guardrails)
1. **Никакой установки в основную систему:** Запрещено модифицировать системные драйверы, загрузчики или системные разделы `drip-pc`.
2. **Изоляция сборок:** Все сборки и промежуточные артефакты должны находиться в пределах рабочего каталога `/home/luuumi-dev/.gemini/antigravity/scratch/rdna3-driver/`.
3. **Разрешения суперпользователя:** У агента нет беспарольного доступа `sudo`. Любые действия, требующие привилегий root, должны быть явно согласованы с пользователем или оформлены в виде готовых изолированных скриптов.
4. **Непрерывность связи:** При тестировании на ноутбуке должен быть гарантирован механизм отката (watchdog / reboot fallback), предотвращающий «окирпичивание» или потерю сетевого доступа к ноутбуку.

## 3. Исследовательский цикл
Перед любым изменением кода:
1. Проверить `memory/decisions.md` и `memory/verified-solutions.md`.
2. Сформулировать гипотезу в `memory/hypotheses.md`.
3. Реализовать минимальный изолированный патч.
4. Запустить верификационные тесты (сначала на хосте под ASan/UBSan, затем при необходимости на тестовом стенде).
5. Зафиксировать результат в `experiments/results.jsonl` и соответствующем файле памяти (`verified-solutions.md` или `failed-experiments.md`).

## 4. Стек инструментов
- Сборка: GCC 16.2 / Clang 22.1, CMake 4.4, Meson 1.12, Make 4.4.
- Анализ: `clang++ -fsanitize=address,undefined`.
- Референсные деревья:
  - `reference/Cobalt64` — референсный проект Navi 48 (macOS IOKit / RADV / Metal).
  - Linux Kernel `drivers/gpu/drm/amd/amdgpu` — источник правды по регистрам и протоколам RDNA 3.
